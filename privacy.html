01

适用范围

本隐私政策适用于由 Brclio 维护的 Brclio Auth Google 账号登录服务，说明我们在身份认证、账号关联及相关支持过程中如何处理个人信息。其他产品的内容、交易或额外功能如有独立隐私政策，应同时阅读相应说明。

本服务的用途是通过 Google 登录识别你的身份、关联 Brclio 账号并展示基本账号资料。Google 账号授权不代表你同意与登录无关的数据处理。

02

我们处理哪些信息

信息类别信息内容与用途

03

Google 登录权限与用途

Brclio Auth 的登录功能仅需要以下三个权限：

  • openid：通过 OpenID Connect 确认 Google 账号身份。
  • https://www.googleapis.com/auth/userinfo.email：获取邮箱及其验证状态。
  • https://www.googleapis.com/auth/userinfo.profile：获取用于账号展示的姓名、头像等基本资料。

本登录功能不需要访问 Gmail 邮件、Google Drive 文件、联系人、日历，或 Google Cloud、Vertex AI、BigQuery、Cloud Storage 资源，也不需要创建、修改或删除你的云资源。我们不会将基础登录授权扩大用于这些功能。

如未来提供确需额外 Google 数据的功能，我们会先说明数据类别、用途和所需权限，更新相关政策，并在需要时重新请求你的授权。

04

信息使用与 Google 数据承诺

我们将个人信息用于完成登录、维护账号关联、展示基本账号资料、防止冒用或滥用、排查登录故障，以及处理你主动提交的请求。

  • 不会出售、出租通过 Google 获取的个人信息，或将其交给数据经纪商。
  • 不会将 Google 用户数据用于广告投放、广告画像或与登录无关的营销。
  • 不会将 Google 用户数据用于训练或改进通用人工智能或机器学习模型。
  • 仅允许为提供服务、安全维护或响应你的请求而确有必要的人员接触相关信息，并限制其访问范围。

Brclio Auth 对通过 Google API 获取的信息的使用与转移，将遵守 Google API Services User Data Policy，包括其中适用的 Limited Use 要求。

05

我们仅在以下情形下向其他接收方提供必要信息：

  • Google：为完成你选择的 Google 登录和身份验证，与 Google 交换必要的认证请求与结果。Google 按其隐私政策处理其服务中的信息。
  • 受托服务提供方：在托管、身份验证、存储或安全维护所必需的范围内处理信息，并限制其用途和访问权限。相关服务可能在你所在地区以外运行。
  • 法律与安全需要：在依法履行义务、回应有效法律请求，或保护用户与服务安全所必需的范围内披露。
  • 经你另行明确同意的其他情形。

本政策网站通过 GitHub Pages 提供。GitHub 可能处理访问网站的 IP 地址、请求时间、浏览器及网络请求等信息，详情见 GitHub 隐私声明。政策网站的托管不代表 Google 登录凭据会提交至此静态网站。

06

存储、安全与保留

账号标识、邮箱及必要的基本资料可在提供账号登录和关联服务期间保留；登录凭据与会话信息仅用于身份验证和维持必要会话。安全记录和支持材料仅在排查问题、防止滥用及履行法律义务所需期间保留，不为与这些目的无关的用途无限期保留。

我们采取与信息性质相适应的访问控制及安全措施，限制不必要的访问和披露。网络传输与存储系统仍可能受到攻击或发生故障，任何安全措施都无法保证绝对安全。

当处理目的结束、你请求删除且没有依法保留的理由时，我们会删除相关信息或使其无法关联到你。若因法律义务或安全事件处理需要保留部分记录，会限制其用途并在可行时向你说明。

07

Cookie 与本地存储

登录流程可能使用必要的 Cookie 或本地存储来维护会话、保存登录状态并防止请求伪造。限制这些必要存储可能影响登录。

本政策网站本身不设置登录 Cookie，不包含广告、统计分析脚本或第三方字体请求。网站托管服务的网络与安全日志按“信息共享与第三方服务”一节及托管商隐私声明处理。

08

撤销授权与删除信息

你可以通过 Google 账号的第三方关联管理查看或撤销 Brclio Auth 的授权。撤销后，后续登录可能需要重新授权；已建立的 Brclio 账号记录不会因此自动删除。

你可以联系 aiyuechuang@gmail.com，请求访问、更正或删除与自己相关的信息，或询问信息处理方式。请说明所用邮箱及请求内容。为防止他人冒用，我们可能要求合理的身份核验，但不会要求你提供 Google 密码或验证码。

删除账号或登录关联可能使你无法继续访问依赖该账号的功能。删除 Brclio Auth 中的信息不会删除你的 Google 账号。对无法立即执行或依法不能全部执行的请求，我们会向你说明原因。
